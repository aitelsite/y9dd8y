# Duck AI فارسی

صفحه‌ای مستقل و واکنش‌گرا برای دسترسی به چت رسمی Duck.ai، با رابط فارسی و راست‌چین.

## نکته مهم
این پروژه کد اختصاصی Duck.ai را کپی نمی‌کند و سرویس رسمی را بازنویسی نمی‌کند. صفحه تلاش می‌کند سایت رسمی را در iframe نشان دهد، اما اگر سیاست‌های امنیتی Duck.ai نمایش درون‌صفحه‌ای را مسدود کند، لینک مستقیم به سایت رسمی ارائه می‌شود. هیچ پاسخ هوش مصنوعی ساختگی تولید نمی‌شود.

## انتشار با GitHub Pages
در مخزن GitHub به **Settings → Pages** بروید، گزینه **Deploy from a branch** را انتخاب کنید، شاخه `main` و پوشه `/ (root)` را تنظیم و ذخیره کنید. پس از آماده‌شدن انتشار، آدرس سایت در همان بخش نمایش داده می‌شود.
